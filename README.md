# 📈 Sales & Profit Dashboard (Power BI)

An interactive Power BI report analyzing sales and profit performance at the order level.

## 🧩 Data Model
The report connects two core tables:
- **Orders** – order-level details including Order Date with a full Date Hierarchy (Year → Quarter → Month → Day)
- **Order Details** – line-item detail including Profit per order

## 📊 What the Dashboard Shows
- **Sum of Profit by Month**, visualized with a column chart driven off the Date Hierarchy
- Drill-down capability from year down to month for fast trend spotting
- A clean, single-page layout designed for quick executive-style insights

## 🛠️ Tools & Skills
Power BI Desktop · Data Modeling (relationships between Orders & Order Details) · DAX measures (Sum of Profit) · Date Hierarchies · Column Charts

## ▶️ How to Explore
1. Download `Power_BI_Dashboard.pbix` from this repo
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
3. Explore the Profit-by-Month visual and drill through the date hierarchy
